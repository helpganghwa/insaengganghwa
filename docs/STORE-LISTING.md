## 6. Google Play 설문 답변

본인확인(결제·청소년 보호 시 KG이니시스)과 채팅·진단 로그가 누락되기 쉬우니 표를 그대로 옮겨 답한다.

- 수집하지 않음: 위치·연락처·사진/동영상·오디오·캘린더·건강·문자·통화 기록. 카카오 닉네임·프로필 사진도 저장하지 않는다.
- 공유: **제3자 공유 없음**. 결제는 Google Play, 인증은 카카오, 본인확인은 KG이니시스, 광고 전환 측정은 Google·카카오가 **처리자**로 수행(위탁이지 공유가 아님).
- ⚠ **광고 전환 측정이 실서비스에서 돈다**(`app/layout.tsx` gtag AW-18402269363 + KakaoPixel). Play '광고' 항목은 **앱 내 광고 노출**을 묻는 것이라 '없음'이 맞지만, 데이터 보안의 기기 ID 목적에는 '광고 또는 마케팅'을 함께 체크해야 방침(§1 수집·§5 위탁·§8 쿠키)과 일치한다.
- 전송 중 암호화: 예. 삭제 요청: 예 — 앱 내 설정 > 계정 탈퇴, 문의 병행.
- 데이터 보안 관행: 독립 보안 검토 없음.

**콘텐츠 등급(IARC)** — 게임: 폭력 = 만화적 폭력(픽셀 몬스터 전투, 유혈 없음) · 성적 내용 없음 · 언어 없음 · 약물 없음 · 도박 요소: 실제 돈 도박 없음, **확률 기반 아이템 있음(랜덤 보상 상자·확률 강화)** · 사용자 상호작용: 있음(채팅·친구) · 위치 공유 없음 · 디지털 구매 있음.

**앱 콘텐츠** — 타겟층 만 13세 이상(아동 대상 아님) · 광고 없음 · 뉴스 앱 아님 · 정부 앱 아님 · 금융 기능 없음 · 건강 앱 아님 · 앱 액세스: 로그인 필요 → 심사 계정 제공(아래 §8).

## 7. App Store 설문 답변

**앱 개인정보(영양 라벨)** — 사용자와 연결된 데이터: 이메일·사용자 ID·구매 내역·사용자 콘텐츠(닉네임·채팅)·식별자(푸시 토큰). 목적: 앱 기능·분석 없음·추적 없음. "이 앱은 데이터를 추적하지 않습니다".

**연령 등급 설문** — 만화 또는 판타지 폭력: 드물게/경미 · 사실적 폭력 없음 · 성적 내용 없음 · 욕설 없음 · 도박 시뮬레이션 없음 · 무제한 웹 액세스 없음 · 도박/콘테스트 없음 → 예상 4+ (한국 표기 전체이용가와 정합).

**계정 삭제** — 앱 내 설정 > 계정 탈퇴. 심사 노트에 경로 명시.
