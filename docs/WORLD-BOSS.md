# 월드보스

> 운영자가 지정한 구역에 보스가 나타나 48시간 머문다(10-11: 자동 추첨 대신 관리자 소환). 그 구역을 점령한 길드원이 **원정대**를 꾸리고, 누구든 원정대에 참가해 보스에 맞선다. 보스는 누구든 한 방에 쓰러뜨리는 재앙이라 원정대는 차례로 쓰러지면서 피해를 쌓고, 쌓인 피해만큼 전리품이 늘어 원정이 종료되는 순간 **그 구역을 점령한 길드**가 전리품을 길드 세금으로 가져간다. 의도: 점령지가 많은 길드일수록 보스를 자주 만난다(쏠림은 의도이며 완화하지 않는다).

## 1. 출현

- **관리자 소환**(10-11 사용자 확정, 자동 추첨 폐지): 관리자 페이지 `/admin/world-boss`에서 서버·구역을 골라 **즉시** 또는 **예약**(KST 시각, 30일 안쪽)으로 소환한다(`spawnWorldBossByAdmin`, 0233으로 하루 1마리 유니크 해제). 구역당 출현 중·예정은 한 마리 — 시간이 겹치지 않는 예약도 같은 구역엔 둘 수 없다(10-11 사용자; 서버 단위 advisory 잠금 + 구역 행 잠금 + 검사라 화면을 둘 열고 동시에 소환해도 차례로 검사한다). 이미 출현 중·예정인 보스와 머무는 시간이 겹치면(**동시에 2마리**) 화면이 한 번 더 묻고 `allowOverlap`으로 진행한다. 구역을 고르면 **주인 길드 인원 → 원정대 최대 N팀 · 참가 상한 N명**을 참고로 보여 준다(10-11 사용자: 참가 상한이 주인 길드 크기에 묶이는 구조는 유지). 예정은 취소할 수 있다(출현 전엔 원정대가 없다). 특성·약점은 소환 때 고정. 소환·취소는 `admin_actions`(world_boss_spawn·world_boss_cancel)에 남는다. 주인 없는 구역도 고를 수 있지만 경고를 띄운다(원정대를 만들 길드가 없다 — 자동 추첨 시절의 '중립 구역에는 나오지 않는다' 규칙은 관리자 소환으로 바뀌면서 경고로 남았다).
- 5분 크론(`/api/cron/world-boss`)이 출현 시각이 지난 '예정'을 '출현'으로(즉시 소환은 그 보스만 지정해 같은 함수를 바로 호출 — `onlyBossIds`), 종료 시각이 지난 '출현'을 정산해 '종료'로 바꾼다. 종료 시각 = 출현 + 48시간. 자정에 걸쳐도 정산은 그 순간의 주인을 읽을 뿐이라 어긋나는 값이 없다. 정산은 보스 한 마리씩 따로 트랜잭션이고 한 마리가 실패해도 다음 보스로 넘어가며 운영 알림(`raiseOpsAlert`)을 남긴다(10-11 재검사). 종료 시각이 지났는데 크론이 아직 안 돈 몇 분은 화면이 **정산 중**(`settling`)으로 보여 준다 — 신청·출발은 이미 막히고 전리품은 아직 주인에게 가지 않은 상태.
- 몇 마리가 동시에 머물지는 운영자가 정한다(기본은 한 마리, 둘째부터 확인).
- 오픈 때 보스는 **한 종류**다(2026-10-08 확정). 지역 컨셉과 무관한 보스라 어느 땅에 나타나도 같다. 이름은 **잿불의 불사조**, 그림은 잿불 불사조 정면, 무대 배경은 **불씨가 남은 숲**이다(2026-10-09 확정). 상세 히어로와 전투 재생 모두 이 배경을 쓴다. 종류는 아래 '보스 종류' 레지스트리(`boss_code`)로 늘린다.

- **비노출 규칙(10-11 사용자)**: **운영자가 소환한다는 사실은 일반 유저에게 절대 노출하지 않는다** — 위키·화면·푸시·우편·월드 로그·연대기·공지 어디에도 '소환'·'운영자'·'관리자'·'예약' 같은 말을 쓰지 않고, 보스는 그저 **나타난다**. 예정(scheduled) 보스는 유저 조회(지도·상세·홈 배너)에 섞이지 않는다. 운영자 공지를 쓸 때도 "○○에 월드보스가 나타났습니다"까지만.
- **용어(10-11)**: 화면에서는 코드의 단계(stage)를 레이드처럼 **페이즈**로 부른다("7페이즈", "다음 페이즈까지 16만", "8페이즈에서 10페이즈까지 올렸어요"). 약점은 보스 하나에 한 묶음이라(10-11) 페이즈와 무관하다. 문서는 설계 용어 '단계'를 그대로 둔다.
- **용어**: 보스가 머무는 시간이 끝나는 것을 시간·규칙·안내 문구에서는 **원정 종료**("종료까지 45시간", "원정이 종료되는 순간 길드 세금으로"), 이야기 문장(떠난 기록·월드 피드·푸시·연대기)에서는 보스 컨셉의 표현인 **재로 흩어지다**("잿불의 불사조가 재로 흩어지며 ○○의 길드 세금에 전리품을 남겼어요")로 쓴다. '떠나다'는 쓰지 않는다. **'금고'라는 말은 화면·우편·로그에 쓰지 않고 '길드 세금'으로 통일한다**(10-11 사용자: 실제로 들어가는 곳이 길드 관리의 세금 화면).

### 보스 종류(여러 컨셉 전제)
보스는 **종류 코드**(`world_bosses.boss_code`, 0235)로 구분한다. 지금은 `ember_phoenix`(잿불의 불사조) 하나지만 다른 컨셉의 보스가 더해진다는 전제로 짠다(10-11 사용자). 이름·그림(정지·대기 띠·불씨 띠·배경·배경 빛)·이야기 문장(공격 8·맨손 4·반격 8·사라짐 표현 3형)은 `lib/game/world-boss/bosses.ts` 레지스트리가 코드로 찾고, 화면·우편·푸시·월드 로그·연대기 사실은 전부 거기서 받는다. 출현 구역의 `region`은 지역색·구역 꾸밈에만 쓴다(종류와 무관).
- 종류를 더하는 절차: 그림 5종 → 레지스트리 항목(이름·경로·문장 풀·사라짐 표현) → 어드민 소환의 종류 선택지는 자동 → 칭호는 공통 칭호 + 종류별 '첫 ○○ 토벌'.
- 특성(§3)·약점·페이즈·보상 규칙은 종류와 무관한 공통 규칙이다(특성 이름 '황금 깃털' 같은 꾸밈말은 공통으로 쓴다).
- 옛 기록·모르는 코드는 기본 종류로 그린다(화면이 비지 않게).

## 2. 원정대

| 항목 | 규칙 |
|---|---|
| 만들기 | 보스가 있는 구역을 **점령한 길드의 길드원만**(`NOT_OWNER_GUILD` — 거주 무소속은 만들 수 없다. 홈 배너 우선순위도 같은 기준: 내 길드가 주인인 보스, 10-11 결정 ⑦). 만든 사람 = 원정대장. 한 사람이 같은 보스에 원정대를 둘 만들 수 없다(이미 참가 중이면 불가). |
| 참가 | **모든 유저**가 신청(다른 길드·무소속 포함). 장비가 없어도 신청·참가할 수 있다(피해 0이어도 공격마다 복권을 뽑는다 — 10-11 3차 적대적 감사 지적, 결정 대기). 수락·거절은 대장. 수락되면 참가, 이미 그 보스의 다른 원정대에 있으면 수락 불가. **같은 보스의 여러 원정대에 동시에 신청할 수 있고**(10-10 사용자 — 종전 '대기 중 신청 하나만' 폐기), 한 곳에 수락되면 나머지 신청은 서버가 지운다(`decideJoin`). 거절되면 신청 행을 지워 **다시 신청할 수 있다**(10-11 재검사 — 종전엔 rejected 행이 남아 '이미 신청' 오류). 신청 취소도 행 삭제. |
| 인원 | 최대 10명(대장 포함). 최소 인원 없음. |
| 초대 | **레이드 지목 초대와 같은 방식**(10-11 사용자, 0234 `world_boss_invites`): 대장이 내 원정대 패널의 빈 자리(주황 점선)를 누르면 초대 시트 — 친구/길드원 탭(인원 수), 고정 높이 목록, 행마다 얼굴·이름·접속·전투력·길드, 오른쪽 `초대` 알약(행마다 따로 잠가 여럿 연달아). 정원은 **대원 + 대기 중 초대**로 센다(10-11 3차 — 남은 자리보다 많이 초대하면 패널에 안 보이는 초대가 생기고 수락 순서대로 PARTY_FULL이 나던 것). **초대 = 참여 허가**: 상대에게 푸시 `원정대 초대`가 가고, 상대의 보스 상세에서 그 원정대 모집 카드가 **맨 앞**에 오고, 카드 위를 가로지르는 주황 **머리띠** `○○ 원정대장이 초대했어요`(I2, 10-11 — ✉ 이모지는 뺐다) + 버튼 **`바로 참가`**(신청·수락 없이)로 보인다. 본문은 다른 카드와 같다. 참가 검사는 신청 수락과 같다(모집 중·보스 머무는 중·정원·1인 1번), 참가하면 같은 보스의 다른 신청·초대는 지우고 대장에게 푸시. 이미 다른 원정대에 있는 사람은 `다른 원정대`, 이 보스와 싸운 사람은 `토벌 완료` 회색 알약으로 흐리게 맨 아래(숨기지 않는다 — 왜 못 부르는지 보이게). 대기 중 초대는 정원에 세지 않고 빈 자리에 흐린 얼굴 + '초대 중'. 해산·출발·정산 때 초대는 지운다. 거절 기능·링크 초대는 없다. 시트에서 `초대함`을 다시 누르면 초대가 취소되고 헤더 토스트 `초대를 취소했어요`로 알리며, 원정대가 가득 차면 목록 위에 `원정대가 가득 찼어요. 자리가 나면 초대할 수 있어요.`를 띄운다(10-11 사용자). |
| 나가기 | 출발 전에는 참가자가 나갈 수 있고, 나가면 다른 원정대에 다시 신청 가능. 대장이 나가면(탈퇴·추방 포함) 원정대 해산. |
| 내보내기 | 대장이 **출발 전에** 대원을 내보낼 수 있다(10-11 사용자 결정 ⑨, 얼굴을 누르면 확인 팝업). 내보내진 사람은 그 원정대에 다시 신청할 수 없고(신청 행 `kicked`, 0239) 다른 원정대에는 신청할 수 있다. 대장이 다시 초대해 수락하면 풀린다. 알림 없음. |
| 출발 | **대장이 누를 때만**. 자동 출발·모집 시간 제한 없음. 점령전 잠금(23:00~01:00)과 무관하다(출발은 구역 주인을 읽지 않는다 — 10-11). 보스가 떠나면 출발하지 않은 원정대는 해산. |
| 횟수 | **보스 하나에 1인 1번**(`world_boss_party_members (boss_id, user_id)` 유니크). 동시에 머무는 다른 보스에는 따로 1번. 참가 상한(주인 길드 인원 × 10)은 관리자 화면의 참고 표시일 뿐 서버가 막지 않는다(10-11 사용자 결정 ②). |
| 소개글 | 만들 때 한 줄(선택, `WORLD_BOSS_PARTY_INTRO_MAX` 40자, 0231 `intro`). 모집 카드와 내 원정대 패널에 보인다. 나중에 고치는 기능은 없다. |
| 안내 | 평균 공격 횟수 같은 수치 안내나 "출발을 누르면 바로 싸워요" 같은 설명 문구는 두지 않는다(10-10 사용자). 출발은 인원과 무관하게 **확인 팝업**(원정대원 명단 + 전투력 · 합산 전투력 · 취소/출발 같은 크기). |

## 3. 전투 (라운드제)

- 결과는 출발 순간 서버가 시드 RNG(`makeRng('worldboss:<party id>:<서버 난수>')`)로 한 번에 정하고, 화면은 재생만 한다.
- 한 라운드: 살아 있는 원정대원이 **모두 한 번씩 먼저** 공격(피해 = 원정대원 전투력 × U(0.5, 1.2)) → 보스가 원정대원 **한 명을 무작위로 한 방에** 쓰러뜨린다(1라운드부터). 역할·버티기·보스 공격력 수치 없음.
- 원정대가 모두 쓰러지면 끝. 1인 평균 공격 횟수 = (인원+1)÷2(10명이면 5.5회, 5명이면 3회).
- 원정대 피해는 보스 누적 피해에 더해지고, 누적 피해로 단계가 오른다(단계 k 체력 = 75만 × 1.1^(k-1), 서버 공통, 끝없음 — 10-10 특성 도입으로 65만에서 조정). 한 번의 출발 안에서도 단계를 넘기는 순간부터 다음 단계로 친다.
- 기록(`world_boss_parties.finale`): 점령전과 같은 `[공격자, 대상, 피해, 보조값]` 튜플 배열(보스 = 특수 인덱스).

### 원정대원 전투력 (2026-10-09 확정)

- **기본** = 출발 순간 **장착한 장비 3개**의 전투력 합. 기본 아바타도 장착 장비만큼 싸운다.
- **아바타 보너스 +50%(부위별)**: 대표 아바타를 만들 때 입은 장비와 같은 장비를 그 부위에 장착했으면 그 장비 +50%. **약점 장비로 갈아입은 부위도 유지**한다(`avatarBonusOn`: 커스텀 아바타가 있으면 약점 부위는 아바타 매치와 무관하게 +50% — 아바타를 다시 만들 부담 없이 약점을 맞춰 입게, 둘이 겹치면 +150%). 기본 아바타(만든 적 없음)는 아바타 보너스가 없다.
- **약점 보너스 +100%**: 보스의 약점 장비면 +100%. 아바타 보너스와 **더한다**(둘 다면 +150%).
- **약점 묶음은 보스 하나에 하나**(10-11 사용자 — 5페이즈마다 바뀌던 페이즈별 약점은 폐지): 소환 때 부위별 **5개**를 뽑아 48시간 내내 고정한다(활성 카탈로그 부위별 42종 중 5종). 묶음이 하나라 밝혀진 약점이 끝까지 누적되므로 수를 10 → 5로 줄였다(넓어진 약점 10·치명 약점 3). 저장 형식은 그대로 배열(길이 1)이고 `world_boss_weak_reveals.phase`는 늘 0. 시뮬(10-11, 프로덕션 2일 활성 386명·주인 길드 39/38/35명이 10명씩 차례로 출발, 보스 300마리): 옛 7묶음×10 대비 평균 피해 −6%(Winners 19.4→19.1페이즈)로 거의 같아 **1페이즈 체력 75만은 그대로** 둔다 — 작은 풀(무작위 적중률 24%→12%)이 끝까지 누적되는 공개를 상쇄한다.
- **약점 공개 = 맞힌 것만**: 누군가 그 장비를 끼고 공격해 맞혀야 공개된다. 공개된 약점만 상세 화면에 보인다. **누가 밝혔는지는 보이지 않고 보상도 없다**(10-10 사용자: 발견자 기획 삭제 — `world_boss_weak_reveals.finder_*`는 기록용으로만 남는다).
- 시뮬(2026-10-09, 실서버 하루 290명·보스 1,500, 당시 부위별 10개·7묶음 기준): 평균 19단계(10마리 중 8마리 15~22), Winners 20.4·로제 17.7·Phoenix 14.6. 아무 장비로도 공격의 약 58%가 약점 하나 이상을 맞히고, 다들 가장 센 장비만 끼면 약점의 약 24%만 밝혀진다. 최대 변수는 아바타 보급률(아무도 안 맞추면 평균 -2.8단계). 10-11 부위별 5개 단일 묶음 시뮬은 위 '약점 묶음' 항목.

### 3.5 특성 (2026-10-10 확정 9종, 0232)

- 보스마다 소환 때 **구성 칸**(원정대를 어떻게 짜느냐)과 **보스 칸**(약점·보상) 하나씩, 칸마다 70%(`WORLD_BOSS_TRAIT_SLOT_P`)로 뽑아 고정한다 → **0~2개**. 같은 칸 안의 특성은 겹치지 않는다(소수 정예·대군, 넓어진·치명 약점). 옛 행(빈 배열)은 특성 없음.
- 구성(원정대 배율 — 출발 순간 구성으로 전원에게 곱, `worldBossPartyTraitMult`): 🤝 **연합 원정** 길드 2곳 ×1.2 · 3곳 이상 ×1.5 / 🚩 **한 깃발 아래** 가장 많은 길드 1명당 +5%, 10명이면 ×1.5 / 🗡 **소수 정예** 5명 이하로 출발하면 피해 ×2.0 + 공격 보상 ×2(10-11 사용자: 공격 횟수가 3회로 줄어 개인 보상이 45% 깎이던 것을 메운다) / 🛡 **대군** 10명 ×1.3 / 🌬 **떠도는 바람** 무소속 대원 ×1.5(대원별).
- 보스: 🔓 **넓어진 약점** 부위별 10개 / 🧨 **치명 약점** 부위별 3개·약점 보너스 +200%(전투력 3배, 장착 제안·내 전투력 계산도 같은 값) / 🪙 **황금 깃털** 꽝 30%→20%(행운 21%→11%, 표 v2 기준) / 💰 **무거운 보물** 단계 전리품 +15%(체력 그대로, 상자는 3의 배수로).
- 시뮬(10-10, 실서버 290명): 기준 평균 19.2단계에서 연합 원정 +3.4 · 한 깃발 +1.5 · 대군 +1.1 · 넓어진 약점 +1.1 · 치명 약점 +0.3 · 떠도는 바람 +0.1 · 소수 정예 0(10명 유지)/+1.0(×2.0으로 5명씩). 0~2개 추첨 평균 +1.3이라 1단계 체력을 65만 → **75만**으로 올려 평균 19단계 유지. 소수 정예 보상 ×2는 5명 원정대의 1인 보상을 10명 원정대보다 약 9% 높게 둔다(3회×2 = 6회분 vs 5.5회분) — 10-11 재검사에서 지적, 사용자 결정 ⑰로 유지.
- 화면: 상세 히어로 **우측 상단**에 칩(이름만, 세로로, 탭하면 효과 시트(팁 없음)) · 구역 카드 = 우측 상단에 이름만(토벌하기 버튼은 우측 하단) · 전투 재생 = 이름만. **특성 이모지(🤝🚩🗡🛡🌬🔓🧨🪙💰)는 화면에 쓰지 않는다**(10-11 사용자: 💎📦 외 이모지 지양 — 👑 원정대장 표시도 '대장' 태그, ✉·⚔️도 뺐다; 레지스트리의 icon은 관리자 화면용). 모집 카드엔 넣지 않는다. 내 원정대 패널에는 구성 특성의 **적용 상태**(초록 "×1.2 적용 중 · 길드 2곳" / 회색 "5명 이하로 출발하면"), 출발 팝업에는 적용 뒤 합산 전투력 한 줄.
- 저장: `world_bosses.traits jsonb`(코드 배열). 엔진: `drawWorldBossTraits`(소환, 서버 난수) → `simulateWorldBoss(ctx.traits)` · `ensureBossWeak(perSlot)` · `worldBossLootFor(stage, mult)` · `worldBossRollDrop(r, lucky, missDelta)`.

**약점 적중 행운**(2026-10-09 확정, 10-11 비율 유지): 한 공격에서 약점 장비를 **2개 이상** 맞히면 그 공격의 꽝이 30% → **21%**, 나머지 칸은 비율 그대로 약 1.13배(`WORLD_BOSS_LUCKY_*`). 황금 깃털 특성은 꽝 10%p를 더 줄인다(30→20, 행운과 겹치면 11%). 1개 적중은 흔해(공격 58%) 2개 이상으로 둔다 — 시뮬(10-09, 부위별 10개 기준)에서 맞춰 입은 대원 31%·안 맞춘 대원 13%의 공격이 행운이었고, 부위별 5개로 줄인 뒤엔 이 비율이 낮아진다(1인 보상 기대 💎148은 행운 없이 센 값).

## 6. 저장 (0228~0239)

- `world_bosses` — 보스 1마리 1행(0233부터 서버·날짜 유니크 없음 — 관리자 소환으로 하루 여러 마리 가능). 상태 `scheduled → active → left`, 누적 피해·단계·전리품·출현/정산 시 주인.
- `world_boss_parties` — 원정대(보스·대장·길드·상태 `recruiting → departed | disbanded`), 출발 뒤 전투 기록·피해·단계 구간·보상, 출발 멱등 키. `guild_id`는 nullable(0236, 길드 해산 뒤 기록 보존) + 부분 인덱스(0238).
- `world_boss_invites` — 지목 초대(0234, PK (party, user)). 해산·출발·정산 때 지운다.
- `world_boss_weak_reveals` — 밝혀진 약점(보스·부위·카탈로그, `phase`는 늘 0, `finder_*`는 기록용).
- `world_boss_party_members` — 참가자. PK (party, user), **유니크 (boss, user)**. 출발 뒤 공격 횟수·피해·쓰러진 라운드·**뽑은 보상 💎·📦**(0237 — 우편과 같은 값, 내 원정대(종료) 화면이 전투 기록을 다시 읽지 않게. 마이그레이션이 출발한 기록에서 백필한다).
- `world_boss_join_requests` — 참가 신청(PK (party, user), pending/accepted/rejected/**kicked**(0239, 대장이 내보냄 — 재신청 차단 표식)).
- `guilds.tax_pool_boxes` — 길드 세금 상자 칸(총량, 3의 배수, 0236 `>= 0` 검사). `profiles.push_world_boss` — 알림 토글. 우편 종류 `world_boss`.

잠금 순서: world_bosses → world_boss_parties → world_boss_party_members → (정산) guilds — 신청·초대·거절·내보내기는 보스를 `FOR SHARE`, 대원을 넣는 수락·초대 수락과 출발·정산은 `FOR UPDATE`로 잡는다(10-11: 반대 순서로 잡던 교착 수정). 정산의 guilds 잠금은 `FOR NO KEY UPDATE`(길드 해산의 KEY SHARE와 교착 방지, 10-11 3차). 모든 월드보스 트랜잭션은 첫 잠금 전에 `set local lock_timeout = '3s'`(풀러 연결을 오래 물지 않게). 종료 판정은 전부 DB 시계 `now()`. 출발은 멱등 키 + 원정대 행 `FOR UPDATE` + 조건부 상태 전이.

### 세계지도

- 별도 띠·알약 없이 **지도 안에서만** 보인다. 보스가 머무는 구역은 점령전 배치 지도의 라벨 토글처럼 **3초씩 번갈아** 바뀐다: 앞 3초 = 평소(길드 문양 · 구역명), 뒤 3초 = 네모 안 **보스 그림** · 라벨 **월드보스 출현**(테두리도 칸과 같은 금빛으로 발광, 10-11) · **금빛 테두리 발광**(주황 지역색과 구분). 한 주기 6초를 CSS로만 돌려 지도를 다시 그리지 않는다. 구역 위에 따로 띄우는 그림은 없어 다른 요소를 가리지 않는다. 움직임 줄이기면 보스 쪽 모습으로 고정. 누르면 구역 시트(보스 카드·원정대). 리플레이 중엔 숨긴다. 자동 이동은 없다.
- **구역 시트**: 숲 배경 한 장(92px) — 보스는 왼쪽 끝 위아래 정중앙, 그 오른쪽에 `월드보스` 칩 + 이름 · 단계 · 종료까지 남은 시간 · 💎📦 전리품, 오른쪽 가운데 작은 **토벌하기** 버튼(홈 배너와 같은 이름 — 10-11 사용자, 보스 상세로). 색은 보스 팔레트(잿빛 + 불씨 주황). 진행 막대는 두지 않는다(남은 시간으로 오해). 원정 종료 뒤 **24시간**(`WORLD_BOSS_LEFT_NOTE_MS`, 10-11 사용자 48h→24h)은 같은 크기·흑백·정지 그림으로 `원정 종료` 칩 · 최종 N단계 · 오늘/어제 + 종류별 사라짐 문장(재로 흩어졌어요) · 전리품만이고 버튼은 **결과 보기**(`WorldBossZoneCard`). 지도 마커에는 종료 보스를 표시하지 않는다(10-11 사용자: 회색 마커 시안 기각 — 구역 시트에서만).
- 홈 메뉴 세계지도 카드: 보스가 머무는 동안 오른쪽 위에 작은 보스(제목·설명 줄을 가리지 않는 자리), 테두리 발광은 없다.

### 보스 상세 `/world-boss/<id>` (2026-10-10 무대 히어로형으로 개편)
- **목록 페이지는 두지 않는다**(사용자). `/world-boss`는 세계지도로 넘기고, 머무는 보스는 지도 띠가 보여 준다. 출현 푸시는 세계지도로, 원정대 푸시(`/world-boss/party/<원정대 id>`)는 그 보스 상세로 넘긴다.

- 두지 않는 문구(10-10 사용자): "1명당 평균 N번 공격", "장착은 게임 전체에 적용돼요", "N단계부터 약점이 바뀌어요", "○○ 길드원이 원정대를 만들면 여기에 떠요".

### 프로덕션 첫 배포 순서
1. **마이그레이션 먼저**(코드보다 앞): 0228 → 0229 → 0230 → 0231 → 0232 → 0233 → 0234 → 0235 → 0236 → 0237 → 0238 → 0239. 모두 멱등(`if not exists`)이고 `lock_timeout 3s`라 잠금을 못 잡으면 실패로 끝난다 — 한산한 시간에 다시 실행. 0237은 출발 UPDATE가 쓰는 칸이라 **코드 배포 전에 반드시** 적용한다.

3. 코드 배포(master push) → `/api/health` dpl 확인 → `/admin/world-boss`에서 소환 화면이 열리고 구역 선택지에 주인 길드 인원이 보이는지 확인.
4. 첫 소환은 **예약**으로(즉시 소환은 되돌릴 수 없다). 예약은 출현 전까지 취소할 수 있다.
5. **소환 주기 지침(10-11 사용자)**: 이틀에 1마리 안팎, 동시 출현은 1마리. 출시 2주 실측(1인 보상·세금 유입·참가율) 뒤 조정.

### 운영 중
- **수동 종료**(보스를 지금 끝내야 할 때): 어드민 버튼은 없다(10-11 논의). 한 트랜잭션으로 `update world_bosses set leave_at = now() where id = <id> and status = 'active'` + `insert into admin_actions (...)`(action `world_boss_manual_end`, payload에 사유) → 다음 크론(5분 안)이 정산한다. 그 사이 화면은 '정산 중'.
- **연장**: `update world_bosses set leave_at = leave_at + interval '12 hours' where id = <id> and status = 'active'` + admin_actions 기록. 연장한 종료 시각이 자정 공개 창(23:50~00:10 KST)에 걸리지 않게 한다. 모집 중 원정대·초대는 그대로 유효하다. **일반 점검** 중에도 크론은 돌고 원정 액션만 막히므로, 점검 공지를 내면 점검 시간만큼 연장한다(10-11 3차).
- **정산 실패 알림**(`월드보스 정산 실패` ops alert)이 오면: 크론이 5분마다 같은 보스를 다시 집어 **자동 재시도**한다(멱등). 흔한 원인은 길드 행 잠금 대기(세금 수금과 겹침)라 다음 틱에 끝난다. 바로 돌려야 하면 Vercel Cron Jobs의 Run 버튼이나 `curl -H "Authorization: Bearer $CRON_SECRET" https://ganghwa.app/api/cron/world-boss`로 **프로덕션 함수를** 부른다. 로컬 스크립트를 프로덕션 DB에 돌리지 않는다(로컬 VAPID 키로 관리자 푸시가 나가 09-03 구독 삭제 사고와 같은 경로, 10-11 3차). 실패가 이어지면 틱마다 알림이 온다.
- **출발 기록·보스 누적 피해는 되돌리지 않는다**(10-11 3차: 출발한 원정대를 '모집 중'으로 되돌려 다시 출발시키면 피해·우편이 두 번 들어간다 — 스테이징에서 확인). 보상 누락·오류 보정은 어드민 우편 단건으로만.
- **공지 타이밍**: 예약 공지는 :02/:07 틱, 보스 출현은 :03/:08 틱이라 출현 공지는 출현 시각 +10분으로 예약한다. 공지에 '소환·예약·운영'과 다음 출현 일정은 쓰지 않는다.
- **스테이징 테스트**(`tests/world-boss/lifecycle.test.ts`)는 자기 보스 id만 지정해 돌리므로 스테이징의 실제 보스를 정산하지 않는다. 프로덕션 DB에는 돌리지 않는다.
- 프로덕션 조회는 `BEGIN READ ONLY`로만(세션 `SET`은 풀러로 새어 나간다 — 09-23 사고).
