# EXPEDITION — 파견

> 상시 콘텐츠 부재("강화 누르고 이제 뭐함?")를 메우는 시간 기반 원정.
> 철학 정합: 모든 판정은 서버 시계·서버 RNG(§3.1·§3.2), 클라이언트는 표시만.
> 강화와 같은 "걸어두고 잊는" 리듬 — 접속을 강요하지 않고, 돌아올 이유를 만든다.
> 수치 정본은 `lib/game/balance.ts` EXPEDITION_*(docs/BALANCE.md §11), 전 항목 확률 공시 대상(§33).

## 1. 규칙 요약 (A′ — 미션 롤 × 아바타 배정)

- **미션 슬롯**: 고정 슬롯에 서버가 **랜덤 미션(지역)**을 롤해서 올려둔다.
  - 슬롯 해금: **4칸 전부 계정 합산 강화**(보유 장비 강화 레벨 합 = 랭킹 '합산 강화')로만 오픈 —
    슬롯1 **0(처음부터)** · 슬롯2 3,000 · 슬롯3 6,000 · 슬롯4 9,000. **다이아·레벨 해금 없음**(강화가 파견의
    유일한 입구이자 규모). 합산 강화는 현재 레벨 합이라 하락 시 닫힐 수 있다 → 진행 중 파견은 수령까지 유지,
    **새 배정만** 잠금(SLOT_LOCKED). 잠금 카드에 진행도를 노출해 "강화하면 열린다"를 목표로 보여준다.
- **시간은 단일 8시간**: 시간 타입·난이도·시간별 스케일 없음. 슬롯당 하루 1회 체제에서 시간은 선택지가 아니라
  귀환 시각이다. 8h인 이유 — 출발 피크(0·7·11·16시)의 귀환이 같은 날 안에 떨어지고, 귀환 푸시 1회로 두 번째
  접속을 만든다(12h는 저녁 출발분이 새벽 귀환, 2·4h는 "빨리 다시 와야 하는" 숙제).
- **슬롯당 하루 1회**: 판정은 출발 시각(KST 일자) · 수령은 언제든 · 취소 없음 · 수령한 카드는 자정까지 '오늘 완료'로
  남고 자정 이후 첫 진입에서 새 오퍼가 생긴다. 규칙 적용 시작 시각 `EXPEDITION_DAILY_LIMIT_SINCE_ISO` 이전 출발분은 미집계.
- **보상 시작 전 확정**: 미션 생성 시 서버가 본상 분기·수량을 **미리 롤해 카드에 확정 표기**(새로고침 = 보상 리롤).
  **대성공만 수령 단계에서 롤**(귀환의 서프라이즈 유지). 즉 수령 = 확정분 지급 + 대성공 판정 1회.
- **아바타 배정**: 미션당 보유 아바타 **1명**. 파견 중 아바타는 중복 배정 불가(잠금). 기본 아바타도 배정 가능(배율 0).
  배정 팝업은 **그 지역 배율이 가장 높은 아바타를 기본 선택**(카드 탭 → 보내기 2탭) — 다른 아바타를 눌러 바꿀 수 있다.
  배율(§3.2·§3.3)은 시작 시점에 스냅샷 확정된다.
- **새로고침**: 미배정(offer) 슬롯 전체 리롤. 무료 3회/일(계정 공용) 소진 후 💎20/회(파견의 유일한 sink).
  미배정 슬롯은 매일 KST 자정 전체 자동 교체.
- **판정 원칙**: 미션 롤·보상 롤·완료 판정 전부 서버. 클라이언트는 표시만.

## 3. 보상 (⚠ 전 항목 확률 공시 대상 — 게임산업법 §33)

**미션 생성(오퍼) 시** 서버 RNG로 롤해 카드에 확정 표기. rng 순서: 지역 → 본상 분기 → 수량 → (상자면) 부위 n회.

**본상 롤(1회, 셋 중 하나 확정) — 파견 1회분·배율 적용 전**

| 분기 | 확률 | 내용 |
|------|------|------|
| 📦 상자만 | 55% | 보급상자 8~10개 |
| 💎 다이아만 | 20% | 150~290 |
| 📦+💎 둘 다 | 25% | 상자 5~8개 + 다이아 25~60 |

- 세 분기의 기대가치는 상자 1개 = 25💎(견습의 주머니 일간 300/12) 기준으로 정렬(225 / 220 / 205).
- **경제 가드**: 무강화 1슬롯 하루 기대 ≈ 💎57·📦8, 4슬롯(합산 강화 9,000+) ≈ 💎229·📦28. 여기에 축 ③ M(AS)·시너지가
  곱해진다(§3.3 시뮬). 슬롯 수 자체가 강화 진척에 묶여 있어 유입 총량은 상위권에 집중.
- 희귀 롤(레이드 소환권·아바타 생성권)은 v1.5 보류 — §4 이용권 설계는 재개 대비 보존.

### 3.1 대성공

- 수령 시 1회 판정. **기본 5% + 계정 합산 강화 1,000당 +1%p(상한 +20%p)** = 최대 25%(`expeditionCritBp(enhanceSum)`).
  강화가 파견의 질로도 이어지는 매출 연결 축. 대성공이면 상자·다이아 수량 ×2.
- 파견 레벨·XP는 없다. 성장축은 §3.2 시너지·§3.3 아바타 강화 합·대성공(합산 강화) 셋.

### 3.2 지역 시너지 (성장축 ② — 아바타 연계, 가중 방식)

- 배정 아바타의 스냅샷 장비 3종 각각의 **현재 강화 레벨**에 가중을 곱해 합산한 **가중 강화 합 WS**를 §3.3의 M()에 넣는다:
  파견지 지역 일치 ×1.3 · 일반 ×1.15 · 불일치 ×1.0(`EXPEDITION_SYNERGY_MATCH_MULT/GENERAL_MULT`, `expeditionWeightedSum`).
- "지역 장비를 강화할수록 그 지역 파견이 좋아진다"가 수치로 이어지고, 고강 아바타일수록 시너지 효과가 커진다.
- `expeditions.synergy_bp`는 M(WS)−M(AS)(가중으로 늘어난 배율분, 표시·이력용). 배정 팝업 아코디언은 장비별 "×1.3 → +N"과
  "강화 합 / 시너지 적용 / 배율"을 보여준다.

### 3.3 아바타 강화 합 (성장축 ③ — 전투력 아닌 **강화 합**, 권장·최소치 없음, 상한 없음)

- **아바타 강화 합(AS)** = 그 아바타의 생성 스냅샷(`equipmentSnapshot` 카탈로그 key 3종)에 대응하는 내 `user_equipment`의
  **현재** `enhance_level` 합. 카탈로그당 1레코드라 key→레벨 1:1. 기본 아바타·구형 스냅샷·미보유 key = 0.
- **배율 M(AS) = 1 + 2.2 × (AS/1,000)^0.8** — 배정 아바타 AS(시너지 가중 적용 WS)만으로 결정, 상한 없음.
  100→×1.35 · 300→×1.84 · 666→×2.59 · 1,000→×3.20 · 1,500→×4.04 · 2,000→×4.83.
- 최종 = 기본 × M(WS)(`applyMultiplier`, bp 합산). 시뮬: `bun run scripts/sim-expedition.ts --as … --w … --slots … --sum …`.
  조절 손잡이는 `EXPEDITION_AS_MULT_COEF`(2.2)·`_EXP`(0.8). 강화 100마다 시도 시간 2배라 1년 뒤 최상위 AS ≈ 1,300~1,500.
- 하락 리스크 연동: 현재 레벨 기준이라 강화 하락 시 AS가 내려가 배율도 내려간다(자기보정).
- 저장: `expeditions.req_bonus_bp`(시작 시 M(WS)−1 스냅샷).
- 공시: 3분기 확률은 불변. M(AS) 식을 공시 payload에 표기(§33).

## 4. 신규 아이템 — 이용권(voucher) ⏸ v1.5 보류(v1은 상자+다이아만)

소환권·생성권 공용의 범용 테이블(추후 이용권류 확장 대비):

```sql
-- user_vouchers: (user, server, kind)당 1행 카운터 — user_supply_boxes 패턴 미러
create table user_vouchers (
  user_id uuid not null references profiles(id) on delete cascade,
  server_id smallint not null default 1,
  kind text not null,          -- 'raid_summon' | 'avatar_gen'
  count integer not null default 0,
  primary key (user_id, server_id, kind)
);
```

- **소환권 사용**: 레이드 개설 시 소환권 보유하면 우선 소모(다이아 200 미차감).
- **생성권 사용**: 아바타 생성 시 보유하면 우선 소모(profileGenPrice 미차감). escrow는 diamond 0·voucher 1로 원장 기록.

## 5. 스키마

`expeditions` 한 테이블 상태 머신: offer(오퍼, 보상 사전 확정 롤) → running(아바타 배정·시작) → claimed | cancelled.
- 슬롯당 활성(offer|running) 1행 — 부분 유니크 `expeditions_one_active`.
- 파견 중 아바타는 1곳 — 부분 유니크 `expeditions_avatar_busy`.
- `duration_ms`는 시작 시 스냅샷(상수 변경이 진행 중 미션에 소급되지 않게). 신규는 항상 8h.
- `difficulty` 컬럼(enum)은 not null 호환으로 새 행에 'normal' 고정 기록 — 판정·표시 어디서도 읽지 않는다.
- `reward`(오퍼 롤 기본값) / `final_reward`(시작 시 배율 적용 스냅샷) / `crit`(수령 판정) / `req_bonus_bp`·`synergy_bp`.
- `expedition_state`(user×server): 새로고침 일일 카운터(`refresh_kst_day`/`refresh_today`)만 사용. level·xp·slots_purchased·starts_* 컬럼은 미사용.
- 수령: `for update` + `complete_at <= now()` + `status='running'→'claimed'` 조건부 전이(멱등). 지급(상자 upsert + walletAdd)은 같은 tx.

## 6. 서버 API (Server Actions)

- `expeditionBoardAction` — ensureOffers(오퍼 보정·자정 교체·옛 시간표 오퍼 자가 치유) 후 보드.
- `startExpeditionAction(slot, avatarProfileId)` — 슬롯당 하루 1회 게이트(DAILY_LIMIT, 출발 KST 일자), running 유니크, complete_at stamping, 배율 스냅샷.
- `claimExpeditionAction(slot)` — 시계 검증 → 대성공 롤 → 지급 → claimed. 멱등(조건부 전이). 응답에 다음 보드 동봉.
- `refreshAllOffersAction()` — 미배정 전체 리롤, 무료 3회/일 후 💎20.
- 레이트리밋: 전 액션 공용 창(정상 플레이 통과, 연타 봇만 차단).

## 6.5 에셋 (지역 배경 + 몬스터)

- 6지역 × (배경 1 + 몬스터 t1~t4) — 미션 카드·배정 시트 배경. 몬스터 단계는 카드의 **기본 보상 크기**(배율 전 오퍼 롤을 다이아 환산, 상자 1개=25💎: <190 t1 / <220 t2 / <250 t3 / ≥250 t4)로 고른다 — 큰 보상일수록 큰 몬스터, 새로고침하면 함께 바뀌고 카드 생애(대기→진행→오늘 완료) 동안은 불변.

## 7. UI

- **진입**: 홈 메뉴 카드(문구 "오늘 파견 N/M", 수령 대기 배지) + 헤더 "오늘 파견 N/M".
- **화면**: `/expedition` — 헤더 한 줄(대성공 % 알약[탭→파견 안내 팝업: 본상 확률·기본 수량·대성공 산식] · "슬롯마다 하루 한 번 · 8시간" · 새로고침) + 슬롯 카드 4장.
- 슬롯 카드(112px): 헤더(지역명·8시간) / 좌 전신 아바타 / 중앙 확정 보상 + 상태('파견 대기'·'파견 완료까지 N시간 N분 N초'·'파견 완료'·'내일 다시 보낼 수 있어요') / 우 몬스터(보상 크기 단계) / 하단 진행 게이지. 카드 전체가 탭 대상, 버튼 없음.
- 배정 팝업: 미니 카드(선택 아바타 기준 확정 보상) + 아바타 목록(배율 높은 순, 기본 선택 = 최고 배율) + 선택 행 아래 장비 3종·계산식 아코디언.
- 수령 팝업: 💎·📦무기·📦방어구·📦장신구 4칸 카운트업 + '기본 × 배율(× 2)' 계산줄. 대성공은 2단 공개(일반 → 황금 섬광과 함께 2배).
- 낙관적 UI: 배정/새로고침/수령 즉시 반영, 서버 보드로 수렴. 수령 팝업만 서버 응답 대기(대성공은 서버 롤).
- 귀환 푸시: 5분 크론(`push-expedition-ready`), 유저별 묶음, `push_expedition` 토글.

## 9. 후속 검토

- **자동 수령**: 완료 후 미수령이 하루 30건 안팎(평균 16시간 방치). 완료 시 크론이 자동 수령하고 다음 접속에 귀환 팝업을 띄우면 하루 "보내기 1탭"만 남는다. 수령 순간·푸시 동선이 바뀌는 큰 변경이라 단일 8h 전환 후 실측을 보고 결정.
- 새로고침 무료 횟수·유료 단가는 낚시 대상이 줄어든 뒤(시간 타입 폐지) 1주 실측으로 재조정.
