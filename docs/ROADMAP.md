> 아니라 2~3일 전에 실행한다. 경로: Supabase 콘솔 → Settings → Compute and Disk.
> 전환 후: Pool Size 40~50 재조정 검토 + 23시대 창에서 CONNECT_TIMEOUT 재발 여부로 검증.
